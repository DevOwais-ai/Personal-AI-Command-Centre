# Database Schema

## Core Tables

### users
Stores application users.

### integrations
Stores connected external platforms and OAuth credentials.

### contacts
Stores people the user communicates with.

### conversations
Stores conversations across connected platforms.

### messages
Stores individual messages.

### tasks
Stores user tasks and AI-generated tasks.

### appointments
Stores meetings and calendar events.

### reminders
Stores scheduled reminders.

### notifications
Stores system notifications.

### ai_actions
Stores AI decisions and actions.

### automation_logs
Stores n8n and automation execution logs.
